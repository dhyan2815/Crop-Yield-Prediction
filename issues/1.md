# Crop selection not affecting yield prediction

## Description

I'm testing the crop yield prediction website. The prediction workflow requires:
1. Select a crop
2. Select the year
3. Select pesticide usage (in tons)

Based on these inputs, the system predicts the yield and displays the historical yield trend.

## Issue

When I change the crop while keeping the year and pesticide usage values constant, the prediction value (which should be in kg/ha) does not change. The prediction remains the same regardless of the crop type selected. However, the prediction value does change when I modify the pesticide usage.

## Current Implementation

The prediction logic uses Python with:
- Linear regression model
- Random forest model
Both models are trained on yield data.

## Expected Behavior

The prediction value should change when selecting different crop types, as different crops have different yield characteristics.

## Additional Notes

I suspect there's a logical flaw or key observation in how the crop selection input is being used in the model predictions. The fact that pesticide usage changes the prediction but crop type doesn't suggests the crop feature may not be properly integrated into the prediction logic.
